# Adblock Test

Онлайн-тест блокировщика рекламы + десктопное Electron-приложение.

- `docs/` — статичный сайт для GitHub Pages: тест **блокировки загрузки** рекламных ресурсов.
  23 приманки этого домена — пути из EasyList / RU AdList (`/ads/cbr.js`, `/ad300.jpg`, `/ad.css` и др.),
  плюс запросы к реальным ad-сетям и контроль загруженного скрипта. Никакой косметики и имитаций показа.
- `src/` — Electron-приложение: локальный сервер с приманками и живым дашбордом вердикта.

## Запуск десктоп-версии
```bash
npm install
npm start
```
