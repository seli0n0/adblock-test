# Adblock Test

Онлайн-тест блокировщика рекламы + десктопное Electron-приложение.

- `docs/` — статичный сайт для GitHub Pages. Открывается в браузере, прогоняет приманки EasyList/RU AdList, косметику, popup/AAB и детекторы — всё клиентски, без бэкенда.
- `src/` — Electron-приложение: локальный сервер с приманками и живым дашбордом вердикта.

## Запуск десктоп-версии
```bash
npm install
npm start
```
